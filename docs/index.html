📖 Project Overview

This is a comprehensive AI-powered brain tumor identification system developed as an MSc Computer Science (SLQF Level 10) research project at the Postgraduate Institute of Science (PGIS), University of Peradeniya.

🎯 Mission: Combine state-of-the-art deep learning with explainable AI to create a clinically trustworthy diagnostic system that assists radiologists and educates medical students.

What Makes This Different?

  • Multi-Model Ensemble: 6 CNN architectures (VGG16/19, ResNet50, MobileNetV2, GoogleLeNet, Custom)
  • Triple XAI: Grad-CAM, LIME, and Saliency Maps with validation metrics
  • Multi-LLM Pipeline: Llama Vision → MedGemma → DeepSeek for clinical report generation
  • RAG Integration: ChromaDB-powered knowledge retrieval for evidence-based answers
  • Uncertainty Quantification: MC Dropout, entropy, confidence intervals
  • Educational Focus: Teaching checkpoints, pitfall warnings, external learning resources

✨ Key Features

🔬 Multi-Model CNN

6 pre-trained architectures with balanced & imbalanced dataset variants for robust classification across 4 tumor types: Glioma, Meningioma, Pituitary, No Tumor

📊 XAI Visualization

Generate Grad-CAM heatmaps, LIME explanations, and saliency maps. Validate with comprehensiveness and sufficiency scores.

📝 12-Section Reports

Structured clinical reports with executive summary, diagnostic findings, differential diagnoses, management plans, and external learning resources

💬 RAG Chatbot

Query medical knowledge base, retrieve similar cases, access clinical guidelines through natural language conversation

📱 Cross-Platform

Ionic React mobile app for Web, Android, iOS with PWA support. Professional UI with drag-drop upload and real-time results

⚡ Fast Inference

Optimized models with ~35-40ms inference time on GPU. Real-time XAI generation and report synthesis

🚀 Quick Start Guide

Prerequisites

  • Python 3.10+ with Conda
  • Node.js 18+ and npm
  • Ollama installed (ollama.ai)
  • OpenRouter API Key (openrouter.ai)
  • GPU recommended (NVIDIA with CUDA)

Backend Setup

# 1. Clone repository
                    git clone https://github.com/yourusername/brain_tumor_app.git
                    cd brain_tumor_app/brain_tumor_identification_api

                    # 2. Create conda environment
                    conda create -n mri_data python=3.10 -y
                    conda activate mri_data

                    # 3. Install dependencies
                    pip install -r requirements.txt

                    # 4. Configure API keys
                    echo "OPENROUTER_API_KEY=your_key_here" > api_key.env

                    # 5. Pull Ollama models
                    ollama pull llama3.2-vision:11b
                    ollama pull medgemma
                    ollama pull deepseek-r1:14b

                    # 6. Run Flask server
                    python app.py
                    # Server starts at http://localhost:5001

Frontend Setup

# 1. Navigate to mobile app
                    cd ../braintumoridentificationapp

                    # 2. Install dependencies
                    npm install

                    # 3. Run development server
                    npm run dev
                    # App opens at http://localhost:5173

                    # 4. Build for production
                    npm run build

                    # 5. Build native Android app
                    npx cap add android
                    npx cap sync android
                    npx cap open android

🎓 Research Context

Degree Program: Master of Science in Computer Science (MSc CS - SLQF Level 10)

Institution: Postgraduate Institute of Science (PGIS), University of Peradeniya, Sri Lanka

Research Focus: Explainable Deep Learning for Medical Image Analysis

Research Questions Addressed

  1. How can CNN decision-making be made transparent to clinicians?
  2. Do multiple XAI methods converge on consistent interpretations?
  3. Can LLMs synthesize multimodal medical data into clinically useful reports?
  4. How does dataset balance affect model performance in medical imaging?
  5. What metrics effectively validate XAI explanations?

Novel Contributions

  • Multi-LLM orchestration (Llama Vision → MedGemma → DeepSeek) for medical report generation
  • XAI validation framework with comprehensiveness and sufficiency metrics
  • RAG-enhanced chatbot for medical knowledge retrieval
  • Uncertainty quantification using MC Dropout and entropy measures
  • Integration of external learning resources (Section 11.5) for continuous education
